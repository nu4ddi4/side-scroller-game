# 《한 번만 더!》 — 2D 횡스크롤 플랫포머 게임 기획안

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 가제 | 한 번만 더! (ONE MORE TRY!) |
| 장르 | 2D 횡스크롤 플랫포머, 트랩 액션 |
| 참고 게임 | 슈퍼 마리오, 스마일모, 아이 워너 비 더 가이 |
| 플랫폼 | PC (Windows) |
| 개발 엔진 | Godot 4 |
| 플레이 방식 | 싱글플레이 |
| 핵심 콘셉트 | 쉬운 조작, 악랄한 함정, 빠른 재도전 |

> 누구나 10초 만에 조작을 익힐 수 있지만, 같은 구간에서 10분 동안 실패할 수도 있는 게임.

복잡한 스토리나 성장 시스템보다는 예상 밖의 함정, 정확한 조작, 빠른 재도전에서 재미를 만든다. 단순히 어렵기만 한 게임이 아니라, 실패 이유를 알아내고 다음 시도에서 극복하는 경험을 강조한다.

## 2. 핵심 게임 시스템

### 2.1 이동 및 조작

| 키 | 동작 |
|---|---|
| A / D 또는 방향키 | 좌우 이동 |
| Space | 점프 |
| R | 즉시 재시작 |
| ESC | 일시정지 |

- 점프 버튼을 누르는 시간에 따라 점프 높이가 약간 달라진다.
- 공중에서도 이동 방향을 조절할 수 있다.
- 공격, 대시, 이단 점프는 초기 버전에서 제외한다.
- 입력 반응과 충돌 판정은 정밀하고 일관되게 만든다.

### 2.2 사망 및 재도전

- 함정에 닿으면 즉시 사망한다.
- 별도 게임 오버 화면 없이 약 0.5초 안에 재시작한다.
- 짧은 사망 애니메이션과 효과음을 제공한다.
- 스테이지별 사망 횟수를 기록한다.
- 실패 페널티는 해당 구간 진행도의 초기화로 한정한다.

### 2.3 체크포인트

- 긴 스테이지에 1~2개 배치한다.
- 활성화된 체크포인트는 반드시 정상적으로 동작한다.
- 체크포인트 뒤에서 실패했다면 이전 구간을 반복하지 않는다.

## 3. 함정 시스템

### 3.1 붕괴형 함정
- 밟으면 사라지는 바닥
- 착지 직전에 무너지는 발판
- 특정 위치에서 떨어지는 천장

### 3.2 반응형 함정
- 접근하면 튀어나오는 가시
- 점프할 때만 움직이는 장애물
- 뒤에서 굴러오는 바위

### 3.3 심리전 함정
- 안전해 보이지만 함정을 작동시키는 코인
- 가짜 출구 또는 골인 지점
- 멈추거나 되돌아갈 때 작동하는 장치

### 3.4 복합형 함정
- 이동 발판과 가시의 조합
- 시간차로 작동하는 장애물
- 연속 점프 중 변화하는 지형

### 함정 설계 원칙
1. 첫 실패는 예상하지 못할 수 있지만, 실패 이유는 이해할 수 있어야 한다.
2. 다음 시도에서는 기억·관찰·숙련으로 회피할 수 있어야 한다.
3. 무작위 사망이나 불명확한 판정을 피한다.
4. 모든 함정에는 재현 가능한 돌파 방법을 제공한다.

## 4. 스테이지 구성

| 스테이지 | 테마 | 주요 기믹 |
|---|---|---|
| 1. 튜토리얼? | 초원 | 낙하 바닥, 갑자기 등장하는 가시 |
| 2. 믿지 마세요 | 동굴 | 가짜 코인, 숨겨진 발판 |
| 3. 타이밍 지옥 | 공장 | 움직이는 가시, 압축기 |
| 4. 안전한 길 | 하늘 | 사라지는 발판, 낙하 함정 |
| 5. 마지막 기회 | 혼합 | 기존 함정 조합, 가짜 골인 |

### 스테이지 1 — 튜토리얼?
1. 이동과 점프를 익힌다.
2. 평범한 바닥이 무너지면서 첫 번째 실패를 유도한다.
3. 해당 구간을 점프로 넘도록 학습한다.
4. 물음표 블록 근처에서 낙하 함정이 발동한다.
5. 골인 지점 직전에 마지막 반전 함정이 등장한다.
6. 함정을 모두 피하면 클리어한다.

반전 함정에도 다시 시도할 때 알아볼 수 있는 시각적 단서를 남긴다.

## 5. 난이도 설계

| 구간 | 목표 |
|---|---|
| 초반 20% | 조작 학습과 간단한 함정 |
| 중반 40% | 예상 밖의 함정과 회피 학습 |
| 후반 30% | 기존 기믹을 활용하는 정밀 조작 |
| 마지막 10% | 골인 직전 반전과 최종 관문 |

짧고 밀도 높은 스테이지를 우선하며, 숨겨진 함정과 눈에 보이는 고난도 장애물을 섞는다.

## 8. 개발 범위와 순서

### 1단계: 기본 플레이
이동, 점프, 충돌, 사망, 즉시 재시작, 카메라 추적

### 2단계: 함정 시스템
붕괴 바닥, 가시, 낙하 오브젝트, 트리거, 움직이는 장애물

### 3단계: 스테이지 제작
5개 스테이지, 체크포인트, 골인 시스템, 난이도 조정

### 4단계: 완성도 개선
그래픽, 사운드, UI, 기록 저장, 플레이 테스트, 버그 수정

### 최소 기능 제품(MVP)

초기에는 스테이지 1개만 제작해 다음을 검증한다.

- 플레이어 이동과 점프
- 함정 3종
- 사망 및 즉시 재시작
- 체크포인트
- 골인 판정
- 사망 횟수 표시

## 9. 설계 시 주의사항

- **억지 난이도 방지:** 보이지 않는 함정만 반복해서 배치하지 않는다.
- **조작 스트레스 방지:** 입력 지연과 불명확한 충돌 판정으로 사망하지 않게 한다.
- **반복 피로 방지:** 이미 통과한 긴 구간을 계속 다시 플레이하게 만들지 않는다.
- **예측 가능성 유지:** 함정이 놀랍더라도 반복 학습으로 극복할 수 있도록 만든다.

## 10. 최종 방향

> 방금은 진짜 억까였는데, 다시 하면 깰 수 있을 것 같다.

게임의 핵심은 콘텐츠의 양보다 조작감, 함정의 연출, 재시작 속도다. 먼저 짧은 스테이지 하나를 완성해 반복 도전 자체가 재미있는지 확인하고, 이후 새로운 기믹과 스테이지로 확장한다.
