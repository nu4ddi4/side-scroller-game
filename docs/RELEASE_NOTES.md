Windows 설치형 배포와 게임 내 업데이트를 추가한 v0.2.0입니다.

- **권장 다운로드: `OneMoreTry-v0.2.0-Windows-x64-Setup.exe`**. 관리자 권한 없이 설치하며 시작 메뉴, 선택형 바탕 화면 바로 가기, 제거 프로그램을 제공합니다.
- 타이틀에서 **업데이트 확인 → 다운로드 → 설치하고 종료**. GitHub의 새 정식 릴리스 설치 파일을 받아 크기와 SHA-256을 검증한 후 실행합니다.
- 시작 시 새 버전을 한 번 확인하며 연결 실패·다운로드 취소 후에도 오프라인 플레이를 계속할 수 있습니다. 베타·이전 버전은 설치하지 않습니다.
- 설치·업데이트·제거 후에도 기존 기록을 유지합니다. ZIP 배포본도 함께 제공합니다.

**v0.1.0 사용자는 이번 설치 파일을 직접 실행해 주세요.** 이전 버전에는 업데이트 기능이 없습니다. ZIP 배포본에서 게임 내 업데이트를 설치하면 설치형으로 전환되므로 이후 시작 메뉴에서 실행하세요.

Windows 10/11 x64 및 OpenGL 3.3 환경용 Godot 4.6.3 게임입니다. 초원 스테이지 1개와 기존 게임 기능을 포함합니다. 실행 파일과 설치 파일에는 코드 서명이 적용되지 않았습니다.

게임 회귀 검사, 일반 입력 전체 스테이지 통과, 실제 HTTP 다운로드 및 손상 파일 검증과 Windows 설치·재설치·실행·제거·기록 보존을 통과한 파일을 배포합니다. 장치별 GPU·오디오와 대화형 설치 UI는 별도 수동 플레이 테스트 범위입니다.

소스와 설치 스크립트는 이 태그를 참고하세요. `feature/* → beta → main` 병합 후 GitHub Actions에서 검증하고 배포합니다.
