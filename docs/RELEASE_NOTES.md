Windows용 첫 MVP입니다. ZIP을 내려받아 압축을 풀고 `OneMoreTry.exe`를 실행하세요. Godot 설치나 인터넷 연결은 필요하지 않습니다.

- 초원 스테이지 1개, 붕괴 발판·돌출 가시·낙하 블록
- 가변 점프, 체크포인트 2개, 약 0.38초 자동 재도전
- 한국어 메뉴·일시정지·클리어 화면, 최고 기록과 총 실패 저장
- 비밀 별과 상단 경로, 자체 제작 칩튠 음악·효과음

이동: A/D 또는 방향키 · 점프: Space · 재도전: R · 일시정지: ESC · 음소거: M · 전체 화면: F11

Godot 4.6.3 기반 Windows 10/11 x64 빌드입니다. 리소스를 EXE에 포함했으며 실행 안내와 라이선스를 함께 제공합니다. 스테이지 2~5와 추가 함정은 후속 개발 범위입니다.
