한 번만 더! / ONE MORE TRY! — Windows MVP v0.1.0

실행: 압축을 푼 뒤 OneMoreTry.exe를 더블 클릭하세요.
별도의 Godot 설치나 인터넷 연결은 필요하지 않습니다.
Windows 10/11 64비트, OpenGL 3.3 호환 그래픽 환경을 대상으로 합니다.

조작
  A / D 또는 ← / → : 이동
  Space             : 점프 (길게 누르면 높게 점프)
  R                 : 체크포인트에서 즉시 재도전 (실패 횟수 +1)
  ESC               : 일시정지 / 계속하기
  M                 : 전체 음소거 전환
  F11               : 전체 화면 전환
  Enter / Tab       : 메뉴 선택 / 메뉴 이동

이 버전에는 초원 스테이지 1개, 함정 3종, 체크포인트 2개,
비밀 경로와 별, 사망 횟수 및 최고 기록 저장이 포함되어 있습니다.
스테이지 2~5는 이후 개발 범위입니다.

힌트: 금 간 바닥, 작은 홈, 흔들리는 물음표를 관찰하세요.
함정에는 일정한 작동 조건과 타이밍이 있습니다.
실패하면 약 0.38초 뒤 마지막 체크포인트에서 다시 시작합니다.
일시정지 메뉴의 '처음부터 재도전'은 해당 도전의 시간과 실패를 초기화합니다.
클리어 시간에는 실패 후 재도전 시간이 포함되고 일시정지 시간은 제외됩니다.
메뉴로 나가거나 프로그램을 종료하면 진행 위치는 초기화됩니다.

기록은 아래 폴더의 records.json에 자동 저장됩니다.
  %APPDATA%\Godot\app_userdata\한 번만 더!\records.json

이 실행 파일은 코드 서명을 적용하지 않은 초기 빌드입니다.
음악과 효과음은 이 프로젝트에서 직접 합성했습니다.
폰트 및 Godot 라이선스는 licenses 폴더에 있습니다.
